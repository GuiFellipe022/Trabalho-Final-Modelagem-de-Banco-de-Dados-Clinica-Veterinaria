# Trabalho-Final-Modelagem-de-Banco-de-Dados-Clinica-Veterinaria
Este projeto foi desenvolvido como Trabalho Final da disciplina de Modelagem de Banco de Dados, com o objetivo de aplicar os conhecimentos adquiridos ao longo do semestre na criação e implementação de um banco de dados relacional de uma clínica veterinária / Petshop.
